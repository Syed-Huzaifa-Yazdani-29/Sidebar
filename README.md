# Basic Sidebar Project

A simple **collapsible sidebar** built using **HTML, CSS, and JavaScript**. This project features a sidebar menu that expands and collapses smoothly.

## 🚀 Features

- **Collapsible Sidebar** 📂  
- **Smooth Transitions** 🎨  
- **Responsive Design** 📱  

## 🛠️ Technologies Used

- **HTML5** - Structure  
- **CSS3** - Styling  
- **JavaScript** - Interactivity
